# Model

The web app expects `classifier.joblib` and `model_card.json` in `models/ics_ids_merged_v1/`.

- `model_card.json`: a copy is in [`docs/results/final_model_card.json`](../docs/results/final_model_card.json).
- `classifier.joblib`: **not yet in this repository.** Add it here (or attach it to a GitHub Release and link it in the root README) before running `app.py`.

`*.joblib` is git-ignored by default; un-ignore it explicitly if it is small enough to commit.
