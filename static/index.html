LLM-Based ICS Intrusion Detection — Live Prototype

Zero-shot classifier over 97 real MITRE ATT&CK ICS techniques. Each event description is embedded with a sentence-transformer model and compared by cosine similarity against every technique's official MITRE description — no attack-specific training. Implements and evaluates the pipeline described (but never empirically tested) in Yoo et al., ICUFN 2024.
